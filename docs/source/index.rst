========================
OpenGlider Documentation
========================

OpenGlider is an open-source toolkit for paraglider and kite design. It provides
Python libraries for geometry (glider, ribs, cells, lines), airfoils, meshing,
and export to OBJ/DXF and other formats, plus an optional FreeCAD workbench.
